# 正文

40 章，12 部分。写作标准见 [STYLE.md](STYLE.md)，提交前跑 `make style`。目录与进度见 [OUTLINE.md](OUTLINE.md)。

## 写作约定

1. 每章一个 `.md`，命名 `NN-slug.md`（如 `08-request-journey.md`）；
2. 开头写"读完你能回答的三个问题"；
3. 所有数字必须能在 `labs/` 里复算，正文标注脚本名；
4. 所有选型必须给"否掉了什么、什么条件下推翻"；
5. 结尾固定四行复盘卡。

## 章节模板

```markdown
# 第 N 章 标题

> 读完你能回答：① … ② … ③ …

## 1. 问题
## 2. 原理
## 3. 设计（含取舍与 ADR 链接）
## 4. 数字（脚本：labs/xxx.py）
## 5. 代码/配置
## 6. 失败模式
## 7. 验收
## 8. 复盘卡
```
